# DeerPrint 🦌

Aplicativo desktop moderno, profissional e de alta precisão para captura de tela, anotações vetoriais, marcações com palavras/tags dinâmicas, desfoque de privacidade (vidro fosco) e salvamento automático.

Construído com o **Design System Sylvan Core** (Dark & Light) e tipografia **Manrope** & **Work Sans**.

---

## ✨ Recursos

- 🦌 **Nova Identidade DeerPrint**: Interface profissional e refinada com o tema *Sylvan Core* (verde musgo, terra tostada e superfícies orgânicas).
- ⌨️ **Atalho Global de Disparo**: Defina qualquer tecla ou combinação nas configurações (`PrintScreen`, `F10`, `Ctrl+Shift+S`, etc.).
- 📐 **Seleção de Área com Retículo & Lupa**:
  - Arraste com o mouse para selecionar qualquer retângulo da tela.
  - Lupa de precisão (Magnifier Loupe) com zoom pixel a pixel e coordenadas em tempo real.
  - Duplo clique ou `Enter` para capturar a tela inteira.
  - Pressione `Esc` para cancelar a qualquer momento.
- 🎨 **Suíte Completa de Anotações & Formas**:
  - Formas: Retângulo, Círculo, Arredondado, Seta, Seta Dupla, Linha, Passos Numerados (1, 2, 3...), Balão de Fala, Pincel Livre e Marca-Texto.
  - Paleta com 32 cores curadas e controle de espessura de traço (1 a 16px).
- 🪟 **Desfoque do Vidro (Glass Blur)**:
  - Oculte dados confidenciais com acabamento translúcido premium nos níveis Leve, Suave, Médio e Forte.
- 🏷️ **Barra Lateral de Palavras / Tags**:
  - Adicione termos frequentes e arraste diretamente para cima da captura como badges coloridos e editáveis.
- 📋 **Cópia Instantânea para Área de Transferência**: O screenshot capturado é imediatamente copiado para a área de transferência do Windows (`Ctrl+V` em qualquer aplicativo).
- 💾 **Salvamento Automático em Disco**: Cada captura e anotação é sincronizada automaticamente na pasta do DeerPrint.
- 🗂️ **Gaveta de Histórico de Capturas**:
  - Painel retrátil com miniaturas de todas as capturas salvas.
  - Clique em qualquer miniatura para recarregar no editor.

---

## 🚀 Como Iniciar

1. Certifique-se de que o **Node.js** está instalado.
2. Na pasta do projeto, inicie o app:
   ```bash
   npm start
   ```
